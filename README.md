# Aditya Upadhyay — Portfolio

A premium, award-level personal portfolio for **Aditya Upadhyay**, Full-Stack Developer and B.Tech CSE student based in Noida, India.

![Aditya Upadhyay Hero Preview](./public/images/me.png)

## 🛠 Tech Stack

- **Vite + React 19 + TypeScript**
- **Tailwind CSS v4** with design tokens
- **Three.js** (lazy-loaded interactive liquid shader and 3D workstation scene)
- **Lenis** smooth momentum scrolling
- **Framer Motion** for micro-interactions
- **Lucide Icons** & **Canvas Confetti**

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

## 📦 Build for Production

```bash
npm run build
```
